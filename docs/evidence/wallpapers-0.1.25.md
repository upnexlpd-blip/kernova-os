# KERNOVA 0.1.25 wallpaper release

Published on 22 November 2026. The Debian 13 testing workflow built all six packages from `446d104` and decoded the 15 4K wallpapers in the packaged artwork check. Stable promotion `ba2137f` reused the six verified package files. Independent verification checked the testing and stable archive signatures and matched the downloaded packages against the pinned SHA-256 manifest. The same artwork check passed on the branding and Welcome packages downloaded from stable. [Testing workflow](https://github.com/upnexlpd-blip/kernova-os/actions/runs/45070447005) · [Stable workflow](https://github.com/upnexlpd-blip/kernova-os/actions/runs/45070784076) · [Package hashes](../../packages/releases/0.1.25.sha256)

The upgrade test ran in a headless QEMU guest with WHPX on Windows, Debian 13 amd64 and kernel `6.12.117+deb13-cloud-amd64`. With `kernova-branding` and `kernova-default-settings` at 0.1.24, `pkcon -p refresh force` refreshed the public stable index. `pkcon -p get-updates` offered 0.1.25 for both packages and `pkcon -p -y update kernova-branding kernova-default-settings` installed them. `dpkg --verify` reported no differences. The guest had 15 KERNOVA wallpapers after the update, including five new Plasma wallpaper entries whose JPEG hashes matched the source files. The test exited with status 0.

The local test transcript is `artifacts/wallpapers-0.1.25/packagekit-debian13-verified/packagekit.log`. The public endpoint and artwork verification logs are `stable-live-endpoint.log` and `stable-artwork.log` in `artifacts/wallpapers-0.1.25/`.
