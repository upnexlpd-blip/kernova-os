# KERNOVA System Help v1 · проверка на 0.1.19

21 ноември 2026. Кандидатот е изграден од гранката `codex/system-help-v1`, започната од Adaptive Engine `5c8baed`. Командата `kernova-doctor` ја испорачува постојниот пакет `kernova-performance`. System Help работи само за времетраењето на командата. Излезот оди на терминалот. JSON содржи верзија на шема, идентификатори на проверки и поправки, статус, доказ, објаснување и следен чекор.

APT потоа ги отстрани `kernova-performance` и зависниот `kernova-welcome` во тестната копија. Извршната команда и модулот исчезнаа, а конфигурацијата и рачниот избор се зачуваа. Со `dpkg --purge` се исчистија конфигурацијата и приватната состојба. Корисничките датотеки ги задржаа контролните суми. При чиста повторна инсталација од истата потпишана архива, командата врати валиден JSON, а Adaptive Engine се подигна со исклучена автоматизација.

## Команди

Во Konsole, како најавениот корисник:

```sh
kernova-doctor scan
kernova-doctor scan --json
kernova-doctor check network
kernova-doctor check network --online
kernova-doctor check audio
kernova-doctor check updates
kernova-doctor check disk
kernova-doctor check adaptive
kernova-doctor fix audio.unmute
```

`check` поддржува и `--json`. `scan --online` ја вклучува посебната Debian HTTPS-проверка со граница од четири секунди и надворешна граница од пет секунди за процесот. Излезниот код 1 означува барем еден `PROBLEM`. Кодот 2 означува `UNKNOWN` без потврден проблем или целосно неприменливи проверки. Кодот 0 означува успешно завршени применливи проверки. Поправката враќа 0 само по прочитано mute off на избраниот излез.

За локална инсталација, отпакувај го доставениот ZIP и од истиот директориум изврши:

```sh
sha256sum -c SHA256SUMS
sudo apt install --no-remove ./kernova-*_0.1.19_all.deb
```

На постари инсталации, APT може да побара Debian-зависности. За офлајн надградба тие треба веќе да се инсталирани или достапни локално. Основната дијагностика работи офлајн по инсталацијата. Финалниот кандидат беше објавен во локалната тестна архива.

## Опсег и ограничувања

- Дискот се проверува на `/`, со одделни резултати за блокови и inode записи. Предупредувањето се активира под 5% достапни за обичниот корисник.
- Проверувањето на пакети користи локален dpkg-аудит и APT-кандидат за `kernova-performance`. Свежината на јавната архива зависи од последното освежување на индексите.
- Поддржаниот аудиоизлез е стандардниот `Audio/Sink` во локалната PipeWire/WirePlumber сесија. При проверката се споредуваат инстанцата на услугата, бројот и серискиот број на јазолот. Извештајот го прикажува само бројот на излезот. Физичката чујност, вистински Wi-Fi, батериските прагови на лаптоп, AC-премините, suspend/resume и потрошувачката остануваат за хардверски тест.
- Adaptive Engine ја почитува забележливата промена на ефективниот профил. PPD не испраќа информација за повторен избор на веќе активниот профил. Претходните мерења и граници на поддршка се во [извештајот за 0.1.18](adaptive-0.1.18.md).
